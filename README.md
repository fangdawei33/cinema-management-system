# 电影院排片与售票管理系统

数据库原理课程设计项目。当前已完成课程设计任务书，系统代码尚未开发。

## 项目范围

采用 Java 前台与 SQL Server 数据库，面向单影院业务，付款采用模拟方式。

- 影片、影厅、座位和场次管理，排片冲突检查。
- 座位图展示、选座售票，防止同一场次座位重复售出。
- 开场前退票、座位释放及订单查询，保证事务一致性。
- 售票量、净票房、上座率统计和影片票房排行。
- 管理员与售票员权限、数据完整性约束、存储过程和触发器。
